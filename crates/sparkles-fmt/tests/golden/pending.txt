# that pass, which then leave this list. One `<language>/<name>` per line (all its
# variants), whitespace, and the reason.

turtle/t4 sections as sort barriers, sorted and as written (before the Turtle printer)
turtle/t5 the SHACL shapes graph example (before the Turtle printer)
turtle/a6 literal shorthands only when the lexical form is the token, tags as written (before the Turtle printer)

nquads/l1 the N-Quads example, default and sorted (before the line formats)
