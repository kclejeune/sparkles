# Apache Jena's TriX tests

These files are copied unchanged from Apache Jena's `jena-arq/testing/RIOT/Lang/TriX`
directory. Jena's `TestTriXReader`, `TestTriXBad` and `TestTriXWriter` use them, and the
unit tests in `crates/sparkles-core/src/trix/tests.rs` run the same cases against the
Sparkles reader and writer.
