# RML-Core test cases

These files come from the `test-cases` directory of the W3C Knowledge Graph Construction
Community Group's RML-Core repository, https://github.com/kg-construct/rml-core, at
commit 82ab28d46803ba66a83c133f1db371a60116f84d (2026-04-20), fetched on 2026-10-24.
Each case directory keeps its mapping, its input files and its expected `output.nq`, and
`manifest.ttl` says which cases expect an error and which base IRI each one uses. The
cases' `README.md` files and the repository's tooling are left out. The files are
unchanged. The repository holds JSON cases only; its CSV and database cases moved to
other modules.
