# Natural-language questions

These evaluations measure question answering with the datasets, models, prompts, budgets and scoring rules stated in the report. Offline validation and paid model measurements have different scopes.

The [results](RESULTS.md) are a
[manual report](../README.md#evidence-and-generated-reports). Read them with the
[run catalog](RUNS.json) and the [shared reference setup](../reference/README.md).
Commands and output formats are in the [harness guide](../../BENCHMARKING.md).

The [comparison of Ask across providers](RESULTS.md#ask-across-providers) gives one
table per set for six Claude and OpenAI models, with the baseline and the final build,
and states the rule that chooses the default model.
