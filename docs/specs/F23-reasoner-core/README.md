# Reasoner core

This spec covers specialized closure operators, complete OWL 2 RL rules, cost-based rule planning, a columnar derived tier, compact provenance, a native n-ary Datalog core, rule frontends and one incremental-maintenance core shared with views. It is partially complete. The closure operators and the OWL 2 RL rule set are built,
and [roadmap item 456](../../ROADMAP.md) holds the remaining work.

Read the [design](SPEC.md), its [candidate phases](SPEC.md#candidate-phases) and its
[acceptance gates](SPEC.md#acceptance-gates). The [implementation plan](PLAN.md) orders
the remaining phases, with the columnar derived tier of item 835 first, the derivation
records of item 836 and the shared maintenance core of item 837 after it, and the rule
frontends of item 838 and the n-ary core of item 839 beside and after them. Its
[Provenance](SPEC.md#provenance) records the design sources.
