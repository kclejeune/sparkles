# X18: Fragment composition

> **Status:** specified

This spec covers immutable fragment generations that index each source version once, and datasets composed by a k-way merge of fragment vocabularies and sorted permutations.
[Roadmap item 458](../../ROADMAP.md) holds the work.

Read the [design](SPEC.md), its [candidate phases](SPEC.md#candidate-phases) and its
[acceptance gates](SPEC.md#acceptance-gates). Its [Provenance](SPEC.md#provenance) records
the design sources.
