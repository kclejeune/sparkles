# Storage consolidation

This spec covers a first-release format cutoff, budgeted readers through one Control trait, a shared commit publish tail, one load plan, partitioned vocabularies with per-range generations, and the remaining replica, clone and format-policy work. It is planned, and
[roadmap item 455](../../ROADMAP.md) holds the work. Items 479, 484 and 830 to 834 hold
the phases that are ready to start.

Read the [design](SPEC.md), its ordered [plan](SPEC.md#plan), its later
[candidate phases](SPEC.md#candidate-phases), its [open decisions](SPEC.md#open-decisions)
and its [acceptance gates](SPEC.md#acceptance-gates). Its [Provenance](SPEC.md#provenance)
records the design sources.
