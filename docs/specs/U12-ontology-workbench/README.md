# Ontology workbench

This spec covers ontology and thesaurus editors, a DL Query tab, a visual SHACL shape
editor and an editable schema diagram. The ontology, thesaurus, DL Query and visual
SHACL phases are built. The diagram remains planned, and
[roadmap item 457](../../ROADMAP.md) holds the wider work. The
[Outcome](SPEC.md#outcome) describes the delivered behavior and remaining dependencies.

Read the [design](SPEC.md), its [candidate phases](SPEC.md#candidate-phases) and its
[acceptance gates](SPEC.md#acceptance-gates). Its [Provenance](SPEC.md#provenance) records
the design sources.
