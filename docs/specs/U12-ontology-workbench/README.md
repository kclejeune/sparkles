# Ontology workbench

This spec covers an ontology editor in the web UI with class, property and individual trees, entity frames, a SKOS thesaurus editor, a DL Query tab and an editable schema diagram. The ontology editor and the DL Query tab are built, the other
phases are planned, and [roadmap item 457](../../ROADMAP.md) holds the work. The
[Outcome](SPEC.md#outcome) describes the editor, its Manchester input and the DL Query tab.

Read the [design](SPEC.md), its [candidate phases](SPEC.md#candidate-phases) and its
[acceptance gates](SPEC.md#acceptance-gates). Its [Provenance](SPEC.md#provenance) records
the design sources.
