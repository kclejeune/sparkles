# ML and probabilistic integration

This spec covers integration with ML pipelines, model registries and probabilistic engines through Croissant, Parquet, MLflow, Hugging Face Hub, ONNX, KServe, Triton, Feast, OpenLineage, PSL and ProbLog. It is planned, and
[roadmap item 463](../../ROADMAP.md) holds the work.

Read the [design](SPEC.md), its [candidate phases](SPEC.md#candidate-phases) and its
[acceptance gates](SPEC.md#acceptance-gates). Its [Provenance](SPEC.md#provenance) records
the design sources.
