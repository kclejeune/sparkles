# Audit and erasure

This spec covers a tamper-evident audit stream of data access and agent activity, personal-data erasure across history and backups, field-level encryption with crypto-shredding, PII detection, comparable digests and verifiable credentials. It is planned, and
[roadmap item 466](../../ROADMAP.md) holds the work.

Read the [design](SPEC.md), its [candidate phases](SPEC.md#candidate-phases) and its
[acceptance gates](SPEC.md#acceptance-gates). Its [Provenance](SPEC.md#provenance) records
the design sources.
