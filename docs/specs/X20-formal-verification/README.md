# Formal verification

This spec covers model checking, bounded proofs and mechanized proofs for the parts of
Sparkles where tests over a corpus can miss whole classes of wrong answers. It is
planned, and [roadmap item 1223](../../ROADMAP.md) holds the work.

Read the [design](SPEC.md), its [candidate phases](SPEC.md#candidate-phases) and its
[acceptance gates](SPEC.md#acceptance-gates). Its [Provenance](SPEC.md#provenance) records
the design sources.
