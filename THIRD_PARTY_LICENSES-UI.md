# Third-party licenses: web UI

The web UI embedded in the `sparkles` binary (served under `/ui/`) bundles code and fonts from the npm packages below. Their licenses and notices follow, each text once, with the packages that ship it. The running server serves this file at `/ui/licenses.txt`.

Generated by the UI build (`ui/scripts/licenses.js`) from the packages in the bundle; `mise run licenses` copies it here. Do not edit.
